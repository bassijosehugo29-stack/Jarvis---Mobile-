# Ícone JARVIS

Arte original gerada para este projeto em 29/10/2026: núcleo circular azul elétrico sobre preto, sem rosto, personagem ou marca copiada. A arte e suas reduções são exclusivamente recursos do launcher; nenhuma imagem foi usada para substituir o núcleo ou a interface interna.

- Foreground adaptativo: WebP de 648 px, com arte central de 396 px (66/108 da camada). Background preto separado.
- Android 26+: adaptive icon; Android 33+: camada monochrome vetorial para ícones temáticos.
- PNGs de fallback: 48, 72, 96, 144 e 192 px.
- Em modos de ícones temáticos do Samsung, o sistema pode recolorir a camada monochrome.

Não existe comparação com o ícone ou a interface do CyberBot comprado: o arquivo original não está acessível nesta execução.
